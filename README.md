# School Website

A school-themed website layout with a navigation bar and embedded map.

**Repository created:** 2021-04-04  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2021-04-04

## Features and implementation

- Collapsible Bootstrap navigation.
- Announcement banner.
- Links for campus life, achievements, news, alumni and contact.
- Google Maps iframe.

## Technologies

HTML, Bootstrap, jQuery.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/school_website.git
cd school_website
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Explore the navigation and map.
